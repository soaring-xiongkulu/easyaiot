# 04 · 物联网设备接入

## 目标

完成「产品模板 → 物模型 → 设备上线 → 影子可见」；工业现场可选云端轮询或 EDGE 边缘采集。

**注意：** 侧栏 **设备管理** 管的是 IoT 产品/设备；摄像头在 **流媒体管理**。两者不要混用入口。

---

## 前置条件

- 已登录且具备产品/设备菜单权限
- EMQX、DEVICE / iot-sink 等依赖正常
- 工业轮询：平台能访问现场端口；EDGE：现场机能连平台 MQTT

---

## 先选哪条接入路径？

| 场景 | 走哪条链 |
|------|----------|
| MQTT / TCP / HTTP 直连终端 | [D1](#操作链-d1产品--物模型--设备标准物联网) |
| 平台直接采 Modbus / OPC UA | [D2](#操作链-d2云端工业轮询) |
| 现场 RS-485 / OT 隔离，边缘采完再上云 | [D3](#操作链-d3-edge-边缘采集) |

## 操作链 D1：产品 → 物模型 → 设备（标准物联网）

| 步骤 | 菜单路径 | 做什么 |
|------|----------|--------|
| 1 | **产品管理 → 新建** | 选产品类型（普通 / 网关 / 子设备 / 视频等）；选协议 MQTT/TCP/HTTP 等；配认证方式 |
| 2 | 进入产品详情 | 编辑物模型：属性 / 服务 / 事件 → **发布**（草稿确认后再发布，避免误伤在线设备） |
| 3 | （可选）协议脚本、接入指引 | 按产品交付联调说明 |
| 4 | **设备管理 → 新建设备** | 选择产品，继承协议与模型 |
| 5 | 打开设备详情「接入指引」 | 复制 MQTT 地址、客户端 ID、用户名密码等给现场 |
| 6 | 现场设备上线 | 看连接/激活状态、设备影子、Topic；网关可看子设备 |

**验收：** 设备在线已激活；影子有属性更新；若定义了服务，可成功调用。

---

## 操作链 D2：云端工业轮询（Modbus / OPC UA）

适用：平台与现场同网或 VPN，由平台主站直接读数。

| 步骤 | 操作 |
|------|------|
| 1 | 产品协议选 **MODBUS_TCP / MODBUS_RTU / OPC UA** |
| 2 | 物模型以**属性**为主并发布 |
| 3 | 创建设备，填写主机、端口、串口或 OPC Endpoint，配置点位与采集周期 |
| 4 | 「测试连接」（若有）通过后保存 |
| 5 | 设备详情看 **点位管理 / 点位影子** |

**验收：** 点位有最新值与历史；允许写值时下行写点成功。

---

## 操作链 D3：EDGE 边缘采集

适用：现场当网关采 Modbus RTU/TCP、OPC UA，经 MQTT 上云。EDGE **没有单独设备页**，云上仍建 **GATEWAY** 产品与设备。

| 步骤 | 操作 |
|------|------|
| 1 | WEB：**产品管理 / 设备管理** 建网关档案，标识与 EDGE 配置一致 |
| 2 | 现场部署 EDGE：配置网关身份、MQTT、采集任务（本地配置或云端下发） |
| 3 | 启动 EDGE，回到 **设备管理** 查看网关在线、子设备自动建档与影子 |
| 4 | （联调）可按 `EDGE` 模块 demo / e2e 脚本验证 |

**验收：** 网关 ONLINE；子设备属性上报；云端写值/配置下发在支持范围内生效。

与「设备管理里的网关」关系：

- 云上：GATEWAY + 子设备拓扑（建档、影子、下发）
- 现场：EDGE 进程**扮演**这台网关去采集

## 扩展：规则与 OTA

| 能力 | 入口 | 说明 |
|------|------|------|
| 规则引擎 | **规则引擎** | 编排 MQTT/Kafka/函数等，做业务联动 |
