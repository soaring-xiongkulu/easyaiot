# 06 · 可视化大屏

## 目标

把设备测点、告警与业务指标做成可投放的指挥/业务大屏（或工艺组态画面）。

---

## 前置条件

- 可视化相关服务已部署（`iot-visualize` / VISUALIZE 编辑器）
- 侧栏可见 **可视化管理**（或「可视化」）
- 数据侧已有可挂数据源：IoT 影子、告警统计等（见 [物联网接入](./04-物联网设备接入.md)、[告警](./03-AI算法任务闭环.md)）

---

## 操作链 F1：从项目到投放

| 步骤 | 菜单 / 操作 | 做什么 |
|------|-------------|--------|
| 1 | **可视化管理** | 进入项目管理 |
| 2 | 新建或选用模板 | Tab：**项目管理 / 模板中心 / 素材库 / 数据源 / 服务部署** |
| 3 | **数据源** | 挂接设备与业务接口，统一字段口径 |
| 4 | 项目「打开编辑器」 | 进入 VISUALIZE 拖拽编排 |
| 5 | 预览确认动效与数据刷新 | 改到可用再发布 |
| 6 | **发布 / 服务部署** | 拿到投放 URL，投到电视墙或浏览器全屏 |
| 7 | （可选）**首页** | 使用平台默认监控指挥大屏作值守首页 |

**验收：** 预览与投放 URL 可打开；关键指标有数；部署状态在线。

---

## 操作链 F2：组态监视（工艺画面）

若项目使用 Web 工艺组态：

| 步骤 | 做什么 |
|------|--------|
| 1 | 在编辑器中把测点绑定到罐体、阀组、电机等图元 |
| 2 | 运行态确认动画与趋势同屏刷新 |
| 3 | 按权限做有限控制（启停、复位等，以现场开通为准） |

**验收：** 班组对着同一套画面能完成监视与交接；异常可从图元定位到测点。

---

## 与首页大屏的关系

| 入口 | 适合 |
|------|------|
| **首页** 监控指挥大屏 | 开箱值守、平台总览 |
| **可视化管理** 自定义项目 | 园区态势、产线 KPI、客户定制屏 |

---

## 本链结束检查

- [ ] 至少一个可视化项目可预览
- [ ] 投放地址可被大屏浏览器打开
- [ ] 数据源与设备/告警口径一致
