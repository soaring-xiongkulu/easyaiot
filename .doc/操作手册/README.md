## 怎么写、怎么读（先看这段）

要把核心功能讲清楚，关键是：**一条链只讲一件事，从业务结果倒推步骤**。

| 原则 | 说明 |
|------|------|
| 按链不按菜单 | 读者问的是「怎么让摄像头告警」，不是「告警事件按钮在哪」 |
| 四段式 | **目标 → 前置条件 → 操作步骤 → 验收标准** |
| 菜单路径写死 | 用「侧栏 → Tab → 按钮」表述，避免「进入某某模块」 |
| 先主干后分支 | 每条链先给最短通路径，再写 ONVIF / 国标 / RTC 等分支 |
| 写清验收 | 每一步结束要能回答：看到什么算成功 |
| 标明边界 | WEB 能做、APP 能做、现场命令才能做，写清楚 |

推荐首次落地顺序（最短闭环）：

```text
登录与权限 → 接入一路摄像头 → 建算法任务 → 看到告警
     ↓
产品/设备上线（可选）→ 通知外发 / TRANSFORM / 大屏（按需）
```
