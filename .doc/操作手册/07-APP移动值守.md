# 07 · APP 移动值守

## 目标

在手机/平板上完成：看设备、控推流与算法任务、处告警；与 WEB 共用同一套后端与账号。

---

## 前置条件

- APP / H5 已部署且可访问（常见于 full 规格）
- 与 WEB 同一 `/admin-api`；用户已有对应权限
- 视频与算法建议先在 WEB 按 [02](./02-视频设备接入.md)、[03](./03-AI算法任务闭环.md) 配好主干

---

## 操作链 G1：移动值守主路径

| 步骤 | APP 入口 | 做什么 |
|------|----------|--------|
| 1 | 登录（可切租户） | 与 WEB 同账号体系 |
| 2 | **设备** | 查看摄像头 / 国标 / NVR 等，预览画面 |
| 3 | **推流** | 查看推流转发，启停与复制流地址 |
| 4 | **算法** | 查看实时/抓拍等任务，启停 |
| 5 | **告警** | 检索告警，看抓拍图与录像 |
| 6 | **模型 / 推理 / 训练** | 巡检模型状态、做移动端图片推理、看训练进度 |
| 7 | **我的** | 资料、租户、消息等 |

**验收：** 同账号下 APP 与 WEB 数据一致；告警证据可打开；H5 可播 FLV/HLS（以现场网络为准）。

---

## WEB ↔ APP 能力对照

| 能力 | WEB | APP |
|------|-----|-----|
| 摄像头预览 / 列表 | ✓ | ✓ |
| 推流转发启停 | ✓ | ✓ |
| 算法任务启停 | ✓ | ✓ |
| 告警查看与取证 | ✓ | ✓ |
| 模型 / 推理 / 训练巡检 | ✓ | ✓（偏查看与轻操作） |
| RTC / 大疆接入向导 | ✓ | 以 WEB 为主 |
| 产品物模型完整编辑 | ✓ | 以 WEB 为主 |
| 可视化编辑 / TRANSFORM 配置 | ✓ | 以 WEB 为主 |
| EDGE 现场部署 | 文档 + 现场 | 不以 APP 为主 |

---

## 建议分工

- **首次接入、复杂配置**：在 WEB 完成  
- **日常巡检、告警处置、临时启停**：用 APP  

---

## 本链结束检查

- [ ] APP 登录成功并可切租户（若启用）
- [ ] 设备可预览、告警可打开证据
- [ ] 算法/推流启停与 WEB 状态同步
