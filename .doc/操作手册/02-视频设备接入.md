# 02 · 视频设备接入

## 目标

把摄像头（或直播源）登记进平台，达到：**列表在线、可预览、可挂推流/算法任务**。

**主入口：** 侧栏 **流媒体管理** → Tab **设备列表**

---

## 前置条件

- 已完成 [登录与基础准备](./01-登录与基础准备.md)
- VIDEO 服务正常；按接入方式准备网络与账号：
  - ONVIF / 直连：同网段或已知 RTSP
  - NVR：Web 账号密码、品牌或 RTSP 模板
  - 国标：现场设备能访问平台 SIP
  - RTC：RTC 模块已启动（管理 API / go2rtc）
  - 大疆：司空 Token 或已有直播源地址

---

## 先选哪种接入？

| 现场设备 | 走哪条链 |
|----------|----------|
| 局域网 IPC，支持 ONVIF/RTSP | [B1 ONVIF / 直连](#操作链-b1onvif--直连-ipc) |
| 录像机多通道 | [B2 NVR](#操作链-b2nvr-批量通道) |
| 国标 SIP 设备/平台 | [B3 GB28181](#操作链-b3-gb28181-国标) |
| Tapo / 涂鸦 / Ring / Nest / 小米 / Wyze / DoorBird / GoPro / 石头等（无原生 RTSP） | [B4 RTC](#操作链-b4-rtc-消费级摄像头) |
| 大疆机场 / 无人机直播 | [B5 大疆](#操作链-b5-大疆机场--无人机) |

接入成功后，统一做 [B6 地图与推流](#操作链-b6-地图布点与推流转发通用)。

---

## 操作链 B1：ONVIF / 直连 IPC

| 步骤 | 操作 |
|------|------|
| 1 | **流媒体管理 → 设备列表 → 添加设备** |
| 2 | 设备类型选 **IPC** |
| 3 | 任选一种方式登记： |
| | · **ONVIF** →「扫描局域网」→ 选设备 |
| | · **跨网段扫描** → 填网段与凭证（海康/大华等） |
| | · **手动填写** → 填 RTSP 等地址 |
| 4 | 保存后到 **分屏监控** 或列表「播放」预览 |

**验收：** 设备列表出现该摄像头、状态在线；画面可播。

---

## 操作链 B2：NVR 批量通道

| 步骤 | 操作 |
|------|------|
| 1 | **添加设备 → NVR** |
| 2 | 「跨网段扫描」或「手动填写」（IP、品牌、RTSP 模板） |
| 3 | 登记后进入 NVR 详情，核对通道列表 |
| 4 | 对通道点播；需要时设置坐标 |

**验收：** 类型为 NVR；通道数量正确；通道可播。

---

## 操作链 B3：GB28181 国标

| 步骤 | 操作 |
|------|------|
| 1 | **添加设备 → 国标** |
| 2 | 「生成配置」，把 SIP 参数复制到现场设备 / NVR |
| 3 | 等待设备主动注册，列表出现「国标设备」 |
| 4 | 打开国标详情 → 通道点播 |
| 5 | （运维）可在页内「节点管理」查看国标节点状态 |

**验收：** 国标设备在线；至少一路通道可点播。

---

## 操作链 B4：RTC 消费级摄像头

适用：原生不提供标准 RTSP、需走厂商 P2P 的品牌。

| 步骤 | 操作 |
|------|------|
| 1 | **设备列表 → 接入 RTC 摄像头**（或添加设备中的 RTC 相关入口） |
| 2 | 选择摄像头平台（Tapo / Tuya / Ring / Nest / 小米 / Wyze / DoorBird / GoPro / Roborock 等） |
| 3 | OAuth / 账号绑定类：先在 go2rtc 管理界面完成绑定，再粘贴源流 URL |
| 4 | 填参 →「预览 URL」确认有流 →「注册设备」 |

**验收：** 设备出现在列表；可预览；后续可挂算法任务。删除设备时应同步清理流配置。

---

## 操作链 B5：大疆机场 / 无人机

| 步骤 | 操作 |
|------|------|
| 1 | **设备列表 → 接入大疆直播** |
| 2 | 选模式：**司空 API 开启直播** 或 **手动直播源** |
| 3 | 设备类型选机场/无人机；填 SN、清晰度或 RTSP/RTMP/HTTP-FLV/HLS 源 |
| 4 | 提交登记，预览画面 |

**验收：** 设备登记成功；可预览；可挂 AI / 告警。

---

## 操作链 B6：地图布点与推流转发（通用）

| 步骤 | 操作 |
|------|------|
| 1 | **地图分布** 或设备「设坐标」/「导入坐标」完成布点 |
| 2 | **推流转发** → 新建任务：选摄像头、推流引擎、协议（RTMP/RTSP 等）→ 启动 |
| 3 | **分屏监控** 确认原画可播；需要研判时勾选「启用 AI」看带框流 |

**验收：** 地图有点位；转发任务运行中；分屏可看画面。

---

## 本链结束检查

- [ ] 至少 1 路设备在线可播
- [ ] （可选）地图已布点
- [ ] （可选）推流转发任务运行中
- [ ] 可进入下一链：[AI 算法任务闭环](./03-AI算法任务闭环.md)
