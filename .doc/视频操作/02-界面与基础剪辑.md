# 02 · 界面与基础剪辑

## 目标

把三支练习片排到时间线上，裁成 **A 3 秒 + B 4 秒 + C 3 秒**，需要的话加 0.5 秒溶解。

## 前置条件

Shotcut 已能打开，见 [01-安装与启动.md](./01-安装与启动.md)。素材在 [demo/素材](./demo/素材)。

---

## 1. 界面四块（先认地方）

```text
┌─────────────┬──────────────────────────┐
│ 播放列表     │  预览监视器               │
│ Playlist    │  看画面、打入出点          │
├─────────────┴──────────────────────────┤
│ 时间线 Timeline                         │
│ V1 视频轨 / A1 音频轨 / 上方字幕条       │
└────────────────────────────────────────┘
右侧或底部：滤镜、导出、属性
```

菜单路径一律按 **视图 → …** 把面板打开。找不到时间线，多半是面板被关了。

---

## 2. 导入素材

1. 文件管理器打开 `.doc/视频操作/demo/素材`  
2. 把 `镜头A_开场.mp4`、`镜头B_主体.mp4`、`镜头C_结尾.mp4` **拖进播放列表**  
3. 点列表里的一条，监视器应能播（蓝 / 绿 / 橙底 + 镜头标题）

验收：播放列表正好 3 条，不是 1 条。

---

## 3. 上时间线

1. 确认底部有 **V1**（视频）。没有就：时间线工具栏 **+** → 添加视频轨  
2. 从播放列表把 A、B、C **按顺序拖到 V1**，让它们首尾相接  
3. 按 `Space` 从头放到尾：应看到蓝 → 绿 → 橙，总长约 **14 秒**

不要把三段叠在同一位置（会互相挡住）。拖的时候看片段左上角时间码，后一段的起点应等于前一段的终点。

---

## 4. 裁剪（三种里会一种即可）

练习目标：

| 片段 | 原长 | 留下 |
|------|------|------|
| A 开场 | 4s | 前 **3** 秒 |
| B 主体 | 6s | 去掉开头 1 秒，留 **4** 秒 |
| C 结尾 | 4s | 大约中间 **3** 秒 |

**方法一：入出点（推荐）**

1. 时间线选中 A，把播放头拖到 3 秒处，按 `O`（出点）  
2. 选中 B，在 1 秒处按 `I`（入点），在 5 秒处按 `O`  
3. 选中 C，在 0.5 秒处按 `I`，在 3.5 秒处按 `O`

**方法二：切开再删**

播放头放到要切的位置 → `S` → 点选多余那一截 → `Delete`

**方法三：拖边缘**

鼠标放在片段左右边缘，指针变双向箭头后往里拖。

裁完总长应约 **10 秒**。若后面的片段没跟着挪，时间线打开 **波纹编辑 / Ripple** 再删，空隙会自动补上。

---

## 5. 溶解转场（可选）

1. 把 B 往左拖，让它和 A **重叠约 0.5 秒**（重叠处会出现转场块）  
2. 同样让 C 和 B 重叠 0.5 秒  
3. 默认就是溶解。点转场块可在属性里改时长

重叠之后总长会略短于 10 秒（参考成片约 **9 秒**）。

拖不动、无法重叠：时间线可能开了「插入/吸附」导致只能首尾接。改用 **覆盖** 拖，或先把后一段稍微抬到空隙里再叠上去。

---

## 6. 常用快捷键

| 键 | 作用 |
|----|------|
| `Space` | 播放 / 暂停 |
| `I` / `O` | 入点 / 出点 |
| `S` | 切开 |
| `Delete` | 删除选中段 |
| `Ctrl+S` | 保存为 `.mlt` 工程 |
| `Ctrl+Z` | 撤销 |
| `J` `K` `L` | 倒放 / 停 / 正放 |

保存工程：文件 → 保存，建议放到 `demo/输出/我的练习.mlt`。下次文件 → 打开工程即可。**工程里记的是素材路径**，不要随便挪 `demo/素材` 目录。

---

## 验收标准

- [ ] 时间线 V1 上有 A、B、C 三段，顺序正确  
- [ ] 总时长约 9–10 秒（做了溶解会更接近 9 秒）  
- [ ] 播放时颜色顺序为蓝 → 绿 → 橙
