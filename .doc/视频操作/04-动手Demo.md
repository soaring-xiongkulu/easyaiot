# 04 · 动手 Demo（对着做一遍）

## 目标

用仓库里的三支色块片，在 Shotcut 里走通：**剪辑 + 配字幕 + 导出**。做完应能独立剪一段监控回放并加上说明字幕。

建议先看 **2 分钟** 演示片，再动手：

- 演示：[demo/输出/操作演示_跟着做.mp4](./demo/输出/操作演示_跟着做.mp4)  
- 答案：[demo/输出/成品参考_已剪辑配字幕.mp4](./demo/输出/成品参考_已剪辑配字幕.mp4)

## 前置条件

- [01](./01-安装与启动.md) 已能打开 Shotcut  
- 素材与字幕在 [demo/](./demo/)

---

## 操作步骤（约 10 分钟）

### 1. 打开软件并摆好面板

启动：终端执行 `shotcut`，或运行 [tools/启动Shotcut.sh](./tools/启动Shotcut.sh)。

**视图** 勾选：播放列表、时间线、滤镜、字幕、导出。

### 2. 导入（两种任选）

**省事：** 文件 → 打开工程 → `demo/练习工程_从这里开始.mlt`（三条已接好、未裁剪）。若时间线上不是三段可单独裁的片子，改用下面「从零」拖 mp4。

**从零练一遍：** 把下面三个文件拖进播放列表，再按 A → B → C 拖到 V1：

- `demo/素材/镜头A_开场.mp4`（蓝，4s）  
- `demo/素材/镜头B_主体.mp4`（绿，6s）  
- `demo/素材/镜头C_结尾.mp4`（橙，4s）

### 3. 排到 V1 / 预览

`Space` 从头播放，应是蓝 → 绿 → 橙，总长约 14 秒。

### 4. 裁剪

| 片段 | 操作 |
|------|------|
| A | 3 秒处按 `O`，只留前 3 秒 |
| B | 1 秒处 `I`，5 秒处 `O`（留 4 秒） |
| C | 0.5 秒处 `I`，3.5 秒处 `O`（留 3 秒） |

总长约 10 秒。细节见 [02](./02-界面与基础剪辑.md)。

### 5. 溶解（可选）

把 B、C 各往前拖，重叠约 0.5 秒。总长会到约 9 秒，与成品参考一致。

### 6. 字幕

1. **视图 → 字幕** → **+** 新建轨  
2. **导入** `demo/字幕.srt`  
3. 选中 V1 → **滤镜 → + → Subtitle Burn In / 字幕烧录**，绑定这条字幕轨  
4. 播放：底部应出现三句中文  

详见 [03](./03-字幕与导出.md)。

### 7. 保存并导出

- `Ctrl+S` → `demo/输出/我的练习.mlt`  
- **导出** → MP4 → `demo/输出/我的练习.mp4`

---

## 验收标准

打开你的 MP4，对照成品参考，三项都满足即过关：

1. 颜色顺序蓝 → 绿 → 橙，没有黑场大空隙  
2. 时长大约 9–10 秒  
3. 画面底部有三句中文字幕，且能对上口型/段落（本练习是色块，对上颜色切换即可）

---

## 下一步（用真素材）

把 `镜头A/B/C` 换成三段监控导出或手机视频，**步骤完全一样**。建议：

- 先在播放列表里看一遍，记下要留的时间码，再上时间线裁  
- 字幕用记事本按 `字幕.srt` 的格式改三句即可（空一行、序号、时间轴、正文）  
- 分辨率不一致时：拖上时间线后选中片段 → 滤镜 **填充/填充边框** 或 **调整大小**，避免画面被拉变形  

重新生成本目录演示片（可选）：

```bash
python3 .doc/视频操作/demo/generate_demo.py
```
