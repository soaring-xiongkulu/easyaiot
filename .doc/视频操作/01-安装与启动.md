# 01 · 安装与启动

## 目标

本机能打开 **Shotcut 26.8.1**，并能导入 `demo/素材` 里的 mp4。

## 前置条件

- Linux x86_64（本仓库这台机器已装好）
- 不需要 root；没有 FUSE 也能用（已解压 AppImage）

## 本机当前安装位置

| 项 | 路径 |
|----|------|
| 启动命令 | `shotcut`（`~/.local/bin/shotcut`） |
| 程序本体 | `~/Applications/squashfs-root/usr/bin/shotcut` |
| AppImage 备份 | `~/Applications/shotcut-linux-x86_64-26.8.1.AppImage` |
| 应用菜单 | 活动区搜索 “Shotcut” |
| 文档内启动脚本 | [tools/启动Shotcut.sh](./tools/启动Shotcut.sh) |

版本验收：

```bash
shotcut --version
# 期望：Shotcut 26.8.1
```

图形界面验收：在桌面会话里执行 `shotcut`（或点应用菜单里的 Shotcut），出现深色主窗口（播放列表 + 监视器 + 时间线）。当前环境若没有显示器，终端里用 `shotcut --version` 即可确认安装。

## 若你要在另一台 Linux 上重装

没有 sudo 时用官方 AppImage（与本机相同版本）：

```bash
mkdir -p ~/Applications
cd ~/Applications
curl -L -o shotcut-linux-x86_64-26.8.1.AppImage \
  https://github.com/mltframework/shotcut/releases/download/v26.8.1/shotcut-linux-x86_64-26.8.1.AppImage
chmod +x shotcut-linux-x86_64-26.8.1.AppImage
# 无 FUSE 时解压后启动（本机就是这样做的）
./shotcut-linux-x86_64-26.8.1.AppImage --appimage-extract
```

有 sudo 时也可以：

```bash
sudo apt install shotcut          # Ubuntu 仓库，版本可能较旧
# 或
sudo snap install shotcut
```

Windows / macOS 到官网下载：<https://www.shotcut.org/download/>

## 建议设置（第一次打开做一次）

1. **设置 → 语言 → 简体中文**，重启 Shotcut  
2. **设置 → 主题** 用 Fusion 深色或浅色，按喜好  
3. **设置 → 代理** 练习片很小，先关掉代理，避免看不懂「为什么画面糊」  
4. **视图** 勾选：播放列表、时间线、滤镜、字幕、导出
