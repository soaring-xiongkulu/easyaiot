# 03 · 字幕与导出

## 目标

把 [demo/字幕.srt](./demo/字幕.srt) 挂到片子上，**烧进画面**，导出可直接发的 MP4。

## 前置条件

时间线已按 [02-界面与基础剪辑.md](./02-界面与基础剪辑.md) 剪好。字幕文件三句，对应成片时间轴：

```text
0.2s–2.8s   欢迎来到 Shotcut 练习片
3.0s–6.8s   主体段落：在时间线里裁掉多余部分
7.0s–9.2s   结尾加上字幕，导出 MP4 即完成
```

若你没做溶解、总长仍是 10 秒，这三条仍然大致落在 A / B / C 上，不必改 srt。

---

## 1. 打开字幕面板

**视图 → 字幕**

没有这条菜单：先 **视图 → 显示隐藏的菜单**，或升级到本机这份 26.8.1。

---

## 2. 导入 SRT

1. 字幕面板点 **+**，新建一条字幕轨（名字随意，如 `中文`）  
2. 点面板上的 **导入**（有的界面在 ▾ 菜单里）  
3. 选中 `demo/字幕.srt`  
4. 时间线 **最上方** 应出现一条字幕条，上面有 3 块

验收：点某块字幕，监视器里还不一定有字——那是下一步「烧录」。但字幕条必须在。

改字：双击字幕块，或在字幕面板的文本框里改。改时长：左右拖字幕块边缘。

手动加一句：播放头放到位置 → 面板里 **+** 添加字幕 → 输入中文 → 拖出时长。

---

## 3. 让字幕真正显示在画面上（烧录）

Shotcut 的字幕轨默认只是「数据」，**预览和导出都要加滤镜才会画到画面上**。

1. 时间线点一下 **V1 轨道头**（选中整条视频轨），或点 tractor / 输出轨  
2. **视图 → 滤镜** → 点 **+**  
3. 搜索 `Subtitle Burn In` 或中文 **字幕烧录**  
4. 加上后，在滤镜属性里选刚才那条字幕轨  

验收：监视器底部出现白底/描边中文，三句话随时间切换。

字太小/位置不对：滤镜属性里改字号、底部边距。中文方块：把字体改成 **Noto Sans CJK SC**（本机已有）。

---

## 4. 不想烧进画面时（软字幕）

导出面板里若有 **「嵌入字幕」/ 文本字幕** 一类选项，可以做成播放器可开关的软字幕。发给别人时，对方播放器必须支持。演示、公众号、微信里一般 **烧录更省事**。

---

## 5. 导出 MP4

1. **视图 → 导出**  
2. 预设选 **MP4**（H.264 + AAC），分辨率保持 1280×720、25fps 即可  
3. 点 **导出文件**，存到 `demo/输出/我的练习.mp4`  
4. 等进度 100%，用系统播放器打开

对照 [demo/输出/成品参考_已剪辑配字幕.mp4](./demo/输出/成品参考_已剪辑配字幕.mp4)：

- 三段顺序蓝 → 绿 → 橙  
- 两段之间有短暂溶解（若你做了转场）  
- 底部三句中文字幕时间对得上  

工程要留着下次改：先 `Ctrl+S` 存 `.mlt`，再导出。导出不是保存工程。

---

## 验收标准

- [ ] 字幕轨上有 3 条，内容与 `字幕.srt` 一致  
- [ ] 监视器能看到烧录字幕（不是只有时间线上的条）  
- [ ] 导出的 MP4 不依赖 Shotcut 就能播，且字幕在画面里
