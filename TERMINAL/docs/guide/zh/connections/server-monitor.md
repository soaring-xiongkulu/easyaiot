# 服务器监控

服务器监控功能通过 SSH 连接到远程 Linux 服务器，实时采集并展示系统运行指标，帮助运维人员快速掌握服务器状态。

> 注意：服务器监控仅支持 **Linux** 远程服务器，依赖 `/proc` 文件系统和 Linux 特有命令。需要 SSH 认证信息（密码或密钥）。

## 打开方式

在已建立的 SSH 连接上，可通过以下入口打开监控面板：

| 入口 | 操作 |
|------|------|
| 标签页右键菜单 | 右键 SSH 终端标签页 → **服务器监控** |
| 面板菜单 | 点击面板标题栏 `...` → **打开服务器监控** |
| 侧边栏右键 | 右键 SSH 连接 → **打开服务器监控** |
| 监控边栏 | 左侧边栏「监控」标签页，跟随当前活动的 SSH 会话展示 CPU / 内存 / 网络，可点击「打开完整监控」进入完整监控页 |

打开后，服务器监控以独立标签页的形式展示，与终端、文件传输等标签页并列，可拖拽排序。

## 界面概览

监控面板分为九个标签页——**性能、进程、端口、磁盘、网卡、服务、系统信息、硬件设备、IPMI**，顶部标签栏可自由切换。

## 性能

实时展示 CPU、内存、磁盘和网络四项核心指标，每 1 秒自动刷新，以 60 点折线图展示最近 1 分钟的历史趋势。CPU / 网络 / 磁盘下方提供可折叠的 **全部核心 / 全部网卡 / 全部磁盘** 明细列表，可按核心、按网卡、按挂载点展开查看。

### CPU

- 总使用率百分比及折线图
- 核心数
- 进程总数和文件句柄数
- 1 分钟 / 5 分钟 / 15 分钟负载均值

### 内存

- 总量、已用、可用、使用率
- Cached 和 Buffers 占用

### 磁盘

- 根分区（`/`）总量、已用、使用率

### 网络

- 接收速率和发送速率（字节/秒），通过两次采样差值计算

## 进程

列出当前 CPU 占用最高的 **30 个进程**，每 1 秒自动刷新。

| 功能 | 说明 |
|------|------|
| 排序 | 默认按 CPU 降序排列 |
| 搜索 | 按进程名、用户名或 PID 过滤 |
| 暂停 | 点击暂停按钮停止刷新，再次点击恢复 |
| 发送信号 | 每行右侧「发送信号」按钮，或点击行打开详情后在底部发送 |
| 进程详情 | 点击任意进程行，右侧滑出详情抽屉 |

### 进程详情

点击进程后，右侧弹出抽屉面板，展示以下信息：

- **基本信息** — PID、PPID、名称、状态、线程数、可执行文件路径、工作目录、完整命令行、启动时间
- **文件描述符** — 总数及分类统计（文件、socket、管道、匿名、设备）
- **虚拟内存** — VmRSS、VmSize、VmPeak、VmData、VmStk、VmExe、VmLib
- **CPU 与上下文切换** — CPU 时间片、自愿/非自愿上下文切换次数
- **I/O 统计** — 读/写字符数和字节数

### 发送信号

在进程详情底部，可选择信号类型向进程发送信号：

| 信号 | 编号 | 说明 |
|------|------|------|
| TERM | 15 | 正常终止（默认） |
| KILL | 9 | 强制终止 |
| HUP | 1 | 挂起，常用于重新加载配置 |
| INT | 2 | 中断，相当于 `Ctrl+C` |

发送前会弹出确认对话框，强制终止（KILL）有额外警告提示。

## 端口

手动刷新，列出所有正在监听的 TCP/UDP 端口。

| 列 | 说明 |
|------|------|
| 协议 | TCP / UDP |
| 本地地址 | 监听地址和端口 |
| 进程 | 进程 PID 和名称 |

## 磁盘

手动刷新，以树形结构列出所有块设备。

| 列 | 说明 |
|------|------|
| 名称 | 设备名，子分区缩进显示 |
| 类型 | disk / part / rom |
| 大小 | 设备总容量 |
| 挂载点 | 挂载路径 |
| 已用 / 使用率 | 已用空间及百分比 |
| 介质 | HDD / SSD / ROM |
| 文件系统 | ext4、xfs 等 |
| UUID | 设备 UUID |
| 厂商 / 型号 | 硬件信息 |

## 网卡

手动刷新，列出所有网络接口。

| 列 | 说明 |
|------|------|
| 名称 | 接口名（eth0、wlan0 等） |
| 状态 | UP / DOWN |
| MAC | MAC 地址 |
| 速率 | 接口速率（Mbps） |
| 类型 | Physical / Bridge / Bond / Virtual / Loopback |
| Bond 主接口 | 所属 Bond 接口（如有） |
| IP 地址 | 绑定的 IP 地址列表 |

## 服务

查看并管理 systemd 主机的系统服务：

- 列表展示 单元 / 状态 / 自启 / 描述，支持搜索与刷新
- 每个服务可执行 启动 / 停止 / 重启 / 开机自启 / 禁用自启 / 查看日志，危险操作有确认提示
- 日志支持自动滚动；点击服务行可查看详情

## 系统信息

展示服务器的静态配置信息与实时时钟：

| 类别 | 内容 |
|------|------|
| 系统 | 用户、运行时间、操作系统、版本号、内核版本、主机名、内网 IP |
| CPU | CPU 型号、核心数、系统架构、CPU 频率、内存总量、磁盘总量 |
| 时钟 | 时区、主机时钟（实时走动）、时钟偏差（正数表示主机快于本机） |

时钟偏差用于发现 NTP 未同步或时钟漂移的主机，排查证书校验、日志时序问题时很有用。

## 硬件设备

以树形表格按类别展示硬件信息：处理器、内存、存储、网络、显示与音频、总线等，列为 ID / 类别 / 厂商 / 设备 / 驱动 / 序列号 / 容量 / 版本，支持搜索。

## IPMI

通过 `ipmitool` 采集服务器的带外管理信息，包含三部分：

- **设备信息** — 产品、厂商、序列号、部件号
- **网络** — IPMI 网络配置
- **传感器** — 传感器 / 数值 / 单位 / 状态 / 来源，支持搜索

主机未安装 `ipmitool` 时会提示不可用。
