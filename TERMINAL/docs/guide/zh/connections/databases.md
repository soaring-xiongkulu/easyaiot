# 数据库

终端 内置数据库客户端，支持主流关系型数据库、Redis、MongoDB 和 Elasticsearch。

## 关系型数据库

![数据库](/imgs/database_light.webp)

### 支持的数据库

**SQL 数据库：**

| 数据库 | 默认端口 |
|--------|----------|
| MySQL | 3306 |
| PostgreSQL | 5432 |
| Oracle | 1521 |
| SQL Server | 1433 |
| rqlite | 4001 |

**NoSQL 数据库：**

| 数据库 | 默认端口 |
|--------|----------|
| Redis | 6379 |
| MongoDB | 27017 |
| Elasticsearch | 9200 |

### 连接参数

| 参数 | 说明 |
|------|------|
| 主机 | 数据库服务器地址；SQL Server 支持 `server\instance` 命名实例写法，未填端口时自动通过 SQL Browser 解析实例端口 |
| 端口 | 各数据库默认端口自动填充 |
| 用户名 | 数据库登录用户 |
| 密码 | 数据库登录密码 |
| 数据库名 | 连接后默认使用的数据库（rqlite 不需要） |
| SSH 隧道 | 开启后可通过 SSH 跳板机加密连接内网数据库，无需暴露数据库端口 |

### 数据库导航

左侧树形面板展示数据库层次结构，连接后可浏览库、表、视图三级对象。

- **展开/折叠** — 点击库名左侧箭头展开表列表，表以网格图标显示，视图以眼睛图标区分
- **搜索** — 顶部搜索框输入关键字，实时过滤表名和视图名，搜索时自动展开所有库
- **双击打开** — 双击库名进入该库的查询页面，双击表名或视图名进入数据浏览页面

右键菜单按节点类型提供操作：

- **库名节点** — 表和视图列表、新建查询、运行 SQL 文件、新建数据库、新建表、删除数据库、刷新
- **表节点** — 打开数据、表结构、复制名称、复制表、导出（仅结构 / 仅数据 / 结构+数据）、清空表、删除表
- **视图节点** — 打开数据、复制名称、导出、删除视图
- **空白处** — 新建查询、新建数据库、刷新

### 数据查询

- **AI 自然语言** — 在顶部 AI 输入框用自然语言描述查询需求，AI 自动获取表结构并生成 SQL 语句
- **SQL 查询** — 输入 SQL 后点击执行或按 `Ctrl+Enter` 运行，结果以表格展示，NULL 值以斜体显示，并显示影响行数与耗时。双击表名默认查询该表前 100 条数据
- **行内编辑** — 双击单元格直接修改（可空列可一键置 NULL），改动先暂存，底部保存条一键批量保存或撤销（需查询结果包含主键列）
- **编辑行 / 新增行 / 删除行** — 表单方式操作，自动检测列类型、默认值和自增列
- **查询历史** — 工具栏「查询历史」面板记录已执行的 SQL、行数与耗时，点击回填重跑
- **导出结果** — 查询结果可导出为 CSV / TXT / JSON
- **筛选与分页** — 结果工具栏可实时筛选；数据浏览模式支持分页（每页 100 / 200 / 500）

### 运行 SQL 文件

库名右键「运行 SQL 文件」可选择 `.sql` 脚本批量执行：成功时提示执行条数与累计影响行数；失败时提示出错的行号、错误详情与失败语句。

### 表和视图列表

双击库名进入，以表格形式展示该库下所有表和视图，支持搜索和排序。每行可执行清空表、删除表/视图，危险操作需输入名称确认。

### 表结构浏览

双击表名进入，左侧树面板展示列信息和索引结构，包括列名、数据类型、是否可空、默认值、主键、自增等详情。

- **编辑列** — 修改列类型、默认值、注释、排序规则
- **新增列** — 添加新列，支持类型自动补全提示
- **删除列** — 确认后删除
- **索引管理** — 新增、删除索引

## Redis

Redis 提供键值数据浏览和管理功能。

![Redis](/imgs/redis_light.webp)

### 连接参数

| 参数 | 说明 |
|------|------|
| 主机 | Redis 服务器地址 |
| 端口 | 默认 6379 |
| 用户名 | Redis ACL 用户名（可选，Redis 6+） |
| 密码 | Redis 认证密码（可选） |
| 模式 | 单机 / 哨兵。哨兵模式需填写哨兵节点地址与主节点名称，可选哨兵用户 / 密码 |
| Key 分组分隔符 | 用于把键名组装为文件夹树的分隔符，默认 `:` |
| SSH 隧道 | 开启后可通过 SSH 跳板机加密连接内网 Redis |

### 键浏览

左侧面板展示所有 Key，支持 **树形显示 / 平铺显示** 切换：树形模式按「Key 分组分隔符」把键名拆成文件夹层级，平铺模式为传统列表。支持按名称搜索过滤。选中 Key 后在右侧查看值内容，不同类型以对应格式展示。

右键菜单提供以下操作：

- **新建** — 新建 Key
- **编辑** — 修改值、重命名
- **管理** — 删除 Key（需确认）、设置或移除过期时间
- **刷新** — 重新加载键列表

### 键操作

- **新建 Key** — 选择数据类型后创建新键，输入 Key 名和值
- **查看/编辑值** — 选中 Key 后查看值内容，点击编辑进入修改模式并保存
- **重命名 Key** — 修改 Key 名称
- **删除 Key** — 选中 Key 后删除，需确认

### TTL 管理

- **设置过期** — 新建或编辑 Key 时设置过期时间
- **移除过期** — 取消过期时间，使 Key 永久保存


## MongoDB

MongoDB 提供文档数据库浏览、查询和行内文档编辑功能。

![MongoDB](/imgs/mongodb_light.webp)

### 连接参数

| 参数 | 说明 |
|------|------|
| 主机 | MongoDB 服务器地址 |
| 端口 | 默认 27017 |
| 用户名 | MongoDB 登录用户（可选） |
| 密码 | MongoDB 认证密码（可选） |
| SSH 隧道 | 开启后可通过 SSH 跳板机加密连接内网 MongoDB。当 SSH 主机运行 `mongod` 时支持自动检测连接入口 |

### 数据库导航

左侧树形面板展示 MongoDB 层次结构：数据库、集合和索引。

- **展开/折叠** -- 点击箭头浏览数据库和集合
- **右键菜单** -- 通过右键菜单创建/删除数据库和集合

### 查询编辑器

- **过滤查询** -- 输入 MongoDB Extended JSON 过滤器后点击执行或按 `Ctrl+Enter` 运行，结果以分页表格展示
- **聚合管道** -- 编写聚合管道进行高级数据处理
- **AI 自然语言** -- 在顶部 AI 输入框用自然语言描述查询需求，AI 根据集合结构自动生成 MongoDB 过滤器

### 文档编辑

- **查看文档** -- 点击文档查看完整内容
- **编辑文档** -- 行内修改文档字段并保存
- **插入文档** -- 插入新文档，支持 JSON 内容
- **删除文档** -- 确认后删除文档

### 索引管理

查看已有索引，创建自定义键和选项的新索引。


## Elasticsearch

Elasticsearch 提供集群、索引与文档的浏览和管理功能。

### 集群浏览

- **集群标签** — 查看集群信息、节点列表、数据节点、分片分布与健康状态
- **索引列表** — 支持搜索索引、隐藏系统索引、新建索引，可打开 / 关闭 / 删除索引

### 文档管理

- **多标签视图** — 每个索引可打开独立的文档标签页
- **文档增删改查** — 新建文档（留空 ID 自动生成）、编辑、删除
- **查询** — 支持简单查询（如 `status:active`）、DSL 查询与 REST 请求三种方式
- **Mapping / Settings** — 查看索引结构与配置
