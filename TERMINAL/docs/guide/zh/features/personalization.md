# 个性化

终端 提供丰富的个性化选项，让终端符合您的使用习惯和审美偏好。


## 应用配置

### 界面主题

| 主题 | 说明 |
|------|------|
| 暗色 | 经典暗色，护眼舒适 |
| 深蓝 | 深蓝科技感 |
| 浅色 | 明亮清新 |
| 跟随系统 | 自动跟随操作系统的深浅色模式 |

### 界面字体大小

整个界面基于统一基准缩放，设置中的「界面字体大小」可调整应用界面文字的基准大小，**调整即时生效**、无需重启。默认值随平台：macOS 基准为 14px，其他平台为 12px。

### 语言

支持 9 种界面语言，切换后无需重启即可生效：

- 简体中文
- 繁體中文
- English
- 日本語
- 한국어
- Deutsch
- Español
- Français
- Русский


## 终端配置

在「终端」标签页中可调整终端的外观和行为。

![终端设置](/imgs/terminal_settings_light.webp)

### 配色方案

内置多款流行配色方案，按深色 / 浅色分组展示；也可**自定义配色**，并支持导入 / 导出 `.itermcolors` 格式的配色文件。

### 字体

- **字体家族** — 下拉列表自动获取系统已安装字体（可勾选「仅等宽」过滤），选择后实时预览
- **备选字体** — 主字体缺少字符（如中文）时使用的备选字体
- **字体粗细** — 常规 / 中等 / 半粗 / 粗体
- **字号** — 范围 8–32，默认 14

### 光标样式

- **光标样式** — 方块 / 下划线 / 竖条
- **光标闪烁** — 开关

### 回滚行数

设置终端可保留的最大输出行数，范围 100–50,000，默认 2,500。超出后早期输出将被丢弃。

### 选中行为

- **无操作** — 选中文本后不做任何处理
- **复制到剪贴板** — 选中文本时自动复制

### 右键行为

- **显示右键菜单** — 右键弹出上下文菜单
- **粘贴剪贴板内容** — 右键直接粘贴

### 中键行为

- **无操作** — 中键点击无反应
- **粘贴剪贴板内容** — 中键单击直接粘贴（默认）

### 智能补全

开启后在终端输入时，根据命令历史和 AI 提供实时补全建议。

### 文本高亮

开启后自动高亮终端输出中的时间戳、IP 地址、关键字、字符串等内容。


## 快捷键

终端 支持自定义快捷键。

![快捷键设置](/imgs/shortcuts_light.webp)

在设置 → 快捷键中，所有可绑定操作按分区展示，可搜索或浏览，点击后按下目标组合键即可完成绑定。支持单键和组合键（含 `Ctrl` / `Alt` / `Shift` / `Meta`）。
