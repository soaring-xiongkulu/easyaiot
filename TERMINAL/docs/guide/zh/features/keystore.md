# 密钥库

密钥库用于统一管理可复用的登录身份（用户名 + 密码 / 私钥），连接时直接引用，避免在每条连接里重复填写凭据。

## 管理身份

入口：**设置 → 密钥库**。

- 列表显示每个身份的 名称 / 用户名 / 认证方式
- 点击 **「新增身份」** 创建，行内可 **「编辑」** 或 **「删除」**
- 在连接表单的认证方式中选择 **「密钥库」** 后，可通过下拉框旁的 **「+」** 按钮直接新建身份，保存后自动选中

## 身份类型

每个身份支持三种认证方式：

| 认证方式 | 字段 | 说明 |
|---|---|---|
| **密码** | 用户名、密码 | 使用登录密码认证 |
| **密钥路径** | 用户名、密钥路径、密钥密码 | 使用本机私钥文件（如 `~/.ssh/id_rsa`），可通过文件选择器选取 |
| **密钥文本** | 用户名、密钥内容、密钥密码 | 内联粘贴 PEM 私钥文本，随身份存储，跨机器可用 |

- **名称** 为必填项
- **密钥密码** 即私钥的 passphrase，私钥无密码可留空
- 切换认证方式后，只保留当前方式对应的字段，不会残留旧密钥信息

## 导入私钥

- **选择密钥文件** — 「密钥路径」方式下点击输入框尾部的文件夹图标，从系统文件选择器选取
- **粘贴 PEM 文本** — 「密钥文本」方式下点击「显示私钥」后粘贴
- **从文件导入** — 「密钥文本」方式下点击「从文件导入」，后端读取并校验文件；未识别到 PEM 私钥头会提示「所选文件不是有效的私钥」

## 在连接中使用

连接表单（SSH / SCP / SFTP / Mosh / X11 等类型）的认证方式中，选择 **「密钥库」** 后从下拉框选择身份即可，连接的用户名与凭据完全由身份提供。

Kerberos、SSH Agent 等其他认证方式与密钥库无关，详见[远程终端](/zh/connections/remote-terminal)。
